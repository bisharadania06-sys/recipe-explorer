# Recipe Finder Explorer  
  
An interactive web application built with React, Vite, and TypeScript for discovering, exploring, and managing delicious recipes using TheMealDB API.  
  
## Features  
- Home Page: Explore a rich list of recipes with smooth loading states and real-time filtering.  
- Advanced Search: Search recipes by name instantly.  
- Recipe Detail View: View details, ingredients list, and instructions.  
- Random Recipe Generator: Discover recipes with a single click.  
- Favorites Manager: Save recipes using browser localStorage.  
- Unit Testing: Tested using Vitest.  
  
## Tech Stack  
- React 19, TypeScript, Vite, React Router DOM, Vitest  
  
## Getting Started  
1. npm install  
2. npm run dev  
3. npx vitest --run
