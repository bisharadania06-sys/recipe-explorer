# Product Requirements Document  
  
## 1. Project Overview  
Recipe Finder Explorer is an interactive web application designed to help users discover, search, and manage recipes seamlessly using data from TheMealDB API.  
  
## 2. Core Features  
- **Home Page**: Displays a grid of recipes with instant search and filtering.  
- **Recipe Detail View**: Master-Detail architecture showing ingredients and instructions.  
- **Random Recipe Generator**: Surprise feature fetching a random meal.  
- **Favorites Manager**: Persistence layer using browser localStorage.  
  
## 3. Tech Stack  
- React 19, TypeScript, Vite, React Router DOM, Vitest, TheMealDB API.
